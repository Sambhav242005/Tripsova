POST /api/trips/generate — the user fills the “Build My Trip” form; this is the request’s journey from the browser, through middleware and auth, into the two-layer planner (rule-based + optional OpenRouter AI), then back as JSON.

POST /api/trips/route-plan — given an origin, a destination (name + lat/lng) and a travel mode, this computes distance, total time, day-by-day segments with coordinates & ISO timestamps, overnight-stop suggestions, and (LAND only) fuel stops.
🚗 LAND · 50 km/h · ×1.25 route · +0.5h · fuel + overnight ✈️ AIR · 750 km/h · +2.5h · single segment 🚢 WATER · 35 km/h · +1.0h · single segment
POST /api/admin/sync/fuel/{destination_id} — admin-only job that pulls real petrol pumps from OpenStreetMap (Overpass API) and stores them as Place(type="FUEL"). This is the data that later appears as fuel stops on LAND trips. Nothing here is invented — it’s OSM data.
